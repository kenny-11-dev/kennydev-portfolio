# KennyDev Portfolio

Static portfolio site for a full-stack web developer in Rwanda.

## Edit your details
Open `index.html` and edit the `C` config block near the top of the `<script>`: WhatsApp number, phone, email, CV link, photo, social links and projects.

## Deploy
Pushes to `main` deploy automatically on Vercel.

## After you have a domain
Replace `YOUR-DOMAIN` in `robots.txt` and `sitemap.xml`.
